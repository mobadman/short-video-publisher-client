操作手册

使用指引

按实际工作顺序整理常用操作、注意事项和问题处理方法。

开始前

确认浏览器不被遮挡

拉取和发布过程中，不要最小化、覆盖或操作软件开启的飞书、抖音和视频号 Chrome。自动化需要识别并操作可见页面。

飞书筛选

不要勾选“筛选结果仅我可见”

按发布日期筛选时保持团队可见，否则软件打开的独立 Chrome 可能读不到当前筛选结果。

异常处理

先看左下角完整报错

工作台只显示简短状态；完整错误会保留在左下角“当前状态”。中断后的未完成项目可以继续执行。

日常发布流程

  1. 选择工作区确认当前平台、发布账号和飞书表格链接。
  2. 准备浏览器打开飞书 Chrome 和发布账号 Chrome；首次使用时完成登录，并保持窗口可见且不被遮挡。
  3. 拉取排期选择发布日期、发布时间方案和素材方案，点击“拉取排期”。
  4. 复核计划红色项目必须修正；商城仅缺封面时显示黄色，默认使用视频首帧。
  5. 执行发布勾选确认边界后点击“发布”；出现异常时查看左下角完整报错。

功能说明与 Q&A

飞书表格需要准备什么？

必需列为【素材链接】【产品类目】【产品型号】【发布时间】。如有【允许发布】列，只有填写“是、允许、可发布、发布、true、1、yes、√”的行会进入计划；商城工作区还会读取【商品链接】。筛选日期时不要勾选“筛选结果仅我可见”。

素材方案怎样生效？

常规方案长期有效，活动方案按起止日期自动生效。活动方案只需保存变化的文案、Tag 和商品短标题，缺失内容继承常规方案；封面在各方案间共用。

发布时间方案会改变旧计划吗？

不会。生成计划时会锁定当次排期规则和具体时间，之后修改或删除方案不会影响已经生成的计划。

素材缺失时怎么看？

红色表示必须处理后才能发布；商城视频仅缺封面时显示黄色，不人工修改会直接使用视频首帧。

发布中断后要重新开始吗？

不需要。软件会保存进度，处理错误后可继续发布未完成项目，已完成项目不会重复执行。

素材库与批量迁移

通过“素材库”页面录入单个产品；首次批量添加可打开方案文件夹或使用 CSV 模板。素材包可按全部工作区、当前工作区或当前方案导出，不包含飞书链接、登录态、Chrome Profile、日志、缓存和计划。
