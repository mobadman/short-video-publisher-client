# 4.2.0 素材工作流需求与实现边界

4.2.0 只改造本地素材解析、素材迁移和工作台布局，不修改抖音主页号、抖音商城号、微信视频号、飞书附件拉取、账号检测和 Chrome Profile 链路。

## 素材方案

- 常规方案继续使用原有文案库、Tag 库、商品短标题库和封面库，不迁移旧素材。
- 活动方案只保存活动文案、Tag 和商品短标题，封面沿用工作区常规封面库。
- 活动方案可以设置开始和结束日期。自动模式按照计划发布日期选择有效方案，到期自动恢复常规方案。
- 工作台只增加轻量“内容方案”选择器，默认自动匹配，也允许对当前新计划手动覆盖。
- 生成计划时记录方案、选择模式、随机种子和每条文案摘要；计划生成后不随素材库更新而变化。

## 文案随机选取

- 文案以产品型号为单位随机洗牌，同一批次的一轮内不重复。
- 一轮使用完毕后重新洗牌，并避免循环交界处立即重复。
- 相同计划的随机种子固定，继续执行、失败重试、查看和编辑不会重新抽取。
- Tag、封面和商品短标题沿用既有选取规则。

## 素材包

- 支持导出全部工作区与全部方案、当前工作区与全部方案、当前工作区与当前方案。
- 包内只允许封面库、文案库、Tag 库、商品短标题库和素材方案目录。
- 不导出飞书链接、账号数据、Chrome Profile、登录态、发布日志、下载缓存、当前计划和本机绝对路径。
- 每个文件写入大小与 SHA-256；导入前完整校验路径、清单和哈希。
- 工作区按稳定 ID 对应。目标机器缺少同名工作区时停止，不猜测映射。
- 同名文件覆盖，其他文件保持；导入过程中失败则恢复原文件。

## 前端调整

- “生成与复核计划”更名为“发布计划”。
- “今日准备度”更名为“发布准备”。
- 发布计划表格不再使用 400px 固定上限，而是根据窗口剩余高度动态展开；内容超出可用空间时才显示内部滚动。
