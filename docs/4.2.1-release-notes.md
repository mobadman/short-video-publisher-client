# 4.2.1 更新说明

4.2.1 重新整理本地素材目录，解决活动方案建立后目录不可见、内部编号无法识别以及首次批量录入效率低的问题。

## 素材中心

- 素材改为“方案优先、平台其次”的统一目录。
- 常规方案和活动方案分开，活动目录使用“方案名称__S001”格式。
- 新建活动方案后立即创建抖音商城、抖音普通和微信视频号目录。
- 封面作为共享素材，不随活动方案重复保存。
- 活动方案缺失的文案、Tag 和商品短标题默认继承常规方案。
- 支持从常规方案或已有活动方案复制内容。

## 批量维护

- 增加“打开方案文件夹”。
- 增加素材结构检查及三个工作区覆盖统计。
- 增加 CSV 批量导入和模板下载，支持追加去重或覆盖同名产品。
- 手工维护仍采用“产品型号.txt”格式，保持内容简单可读。

## 升级安全

- 首次启动只把旧素材复制到素材中心，并逐文件执行 SHA-256 校验。
- 旧素材目录不移动、不删除，可用于人工核对。
- 素材包继续排除飞书链接、Chrome Profile、登录态、发布日志、下载缓存、发布计划和本机绝对路径。
- 抖音、商城、视频号的发布自动化和飞书拉取链路未修改。
