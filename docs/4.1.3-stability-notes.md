# 4.1.3 稳定性修复说明

4.1.3 不增加新的发布功能，处理 4.1.2 生产反馈中的两个稳定性问题。

## 视频号发布回退

- 以 4.0.3 已验证流程为基线，恢复 `slowMo: 100`。
- 恢复从视频号首页点击“发表视频”进入发布页，不再优先直达发布地址。
- 恢复“上传视频 → 正文与 Tag → 等待处理完成 → 短标题 → 定时 → 封面 → 发表”的顺序。
- 恢复较保守的输入、上传轮询和结果确认节奏。
- 保留 4.1.x 的分阶段耗时日志，不改变业务操作。
- 封面入口、编辑窗口、文件输入、裁剪窗口和确认按钮改为真实等待；任一必要环节缺失都会停止，不会无封面继续发表。

## 内置窗口关闭

- 将计划“查看”窗口加入统一 UI 元素注册表。
- 通用关闭函数增加 DOM 后备查找，新窗口即使遗漏注册也能关闭。
- 浏览器冒烟测试覆盖右上角关闭按钮和底部“关闭预览”按钮。

## 保持不变

抖音发布、商城挂车、飞书拉取、本地素材库、账号 Profile、计划缓存、断点续发和发布日志链路不变。

## 4.1.4 补充修复

视频号页面会在“编辑封面”窗口中预加载一个隐藏的“裁剪封面图”节点。4.1.3 会因父窗口包含这段隐藏文字而误判裁剪弹窗已经打开，继而等待不可见的“确定”按钮。4.1.4 改为只接受真正可见的裁剪标题和按钮，同时支持上传后直接点击“确认”以及先“确定”裁剪、再“确认”封面的两种页面流程。
