# 短视频批量发布助手 4.1.2 更新公告

本次版本以 4.0.3 为对比基线，重点补齐素材库维护、商城视频首帧封面策略和发布效率优化，并修复抖音新版发布页“添加标签”变化造成的商城挂车中断。团队统一升级到 **4.1.2**，不要使用中间验证版本 4.1.0 或 4.1.1。

## 主要更新

### 素材库可以直接在软件内维护

- 新增表单式素材维护入口，可按产品型号添加文案、Tag、封面和商城商品短标题。
- 可选择写入一个或多个工作区，继续沿用现有素材目录，不需要手工寻找文件夹。
- 保存前显示标准化后的产品目录名；重复内容会自动去重。
- 跨工作区写入失败时会回滚，避免部分工作区写入成功、部分失败。

### 商城视频支持默认使用视频首帧

- 商城计划仅缺少封面时，不再作为红色阻断错误，而是显示黄色提醒“可发布 · 使用首帧”。
- 未人工补充封面时，发布流程默认使用视频首帧，不再额外上传本地封面。
- 如果同时缺少文案、Tag、商品链接或商品短标题等其他必要素材，仍保持红色阻断，避免误发。

### 发布效率与诊断能力提升

- 视频号优先直接进入发布页，减少无意义的中间页面等待。
- 视频号正文和 Tag 输入提速；抖音正文与 Tag 输入也同步优化。
- 视频号发布日志增加“打开页面、表单就绪、填写内容、等待上传、结果确认”等分阶段耗时，便于继续定位慢点。
- 保持平台明确成功后才进入下一条、每条只点击一次发布和异常即停的规则。

### 修复抖音商城挂车兼容问题

- 兼容抖音将旧版“标签”改名为“添加标签”。
- 标签类型下拉框限定在“添加标签”所在行，避免误点合集、共创等其他控件。
- 修复下拉动画尚未完成就立即判定“没有购物车”的时序问题，改为等待选项实际可见。
- 商品链接、编辑商品窗口和商品短标题输入改为显式等待，降低页面加载速度波动造成的误报。

## 保持不变

- 与 3.1.2、4.0.3 使用相同的应用身份、账号 ID、用户数据目录和 Chrome Profile 目录。
- 升级不会迁移或删除现有登录状态、工作区配置、本地素材、下载缓存、发布计划和发布日志。
- 飞书只读拉取、素材匹配、全量预检、失败即停、断点续发和单次提交原则不变。
- 4.0.3 已有的批次作品链接保存与“一键检查本批次视频”功能继续保留。

## 升级方式

1. 结束正在执行的发布任务并关闭旧版软件。
2. 安装 `短视频批量发布助手 Setup 4.1.2.exe`，可直接覆盖旧版。
3. 打开软件，确认版本显示为 4.1.2，并检查当前工作区和账号状态。
4. 如果此前任务因网页结构变化中断，使用续发功能继续未完成项目；已完成项目不会重复执行。
